# CLI से डेस्क का उपयोग — टर्मिनल और AI एजेंट

आपकी ShareDesk रिपॉज़िटरी में मौजूद एक फ़ाइल `cli/sharedesk.mjs` से डेस्क की फ़ाइलें देखी, डाउनलोड और अपलोड की जा सकती हैं। किसी बाहरी पैकेज की ज़रूरत नहीं, केवल Node 20+ चाहिए। किसी कोडिंग AI (Claude Code, Codex आदि) को यह दस्तावेज़ पढ़ाएँ, तो वह सीधे डेस्क के साथ काम कर सकता है।

## 1. टोकन प्राप्त करें

1. डेस्क में साइन इन करें, दाएँ साइडबार (`»`) को खोलें और **CLI कनेक्ट करें** दबाएँ।
2. चाहें तो लिखें कि टोकन कहाँ उपयोग होगा, फिर **टोकन बनाएँ** दबाएँ।
3. टोकन **केवल एक बार** दिखता है। **टोकन कॉपी करें** से उसे सुरक्षित रखें।

टोकन एक डिवाइस सत्र है जो आपके नाम से काम करता है। व्यवस्थापक उसे उपयोगकर्ता प्रबंधन की डिवाइस सत्र सूची (`CLI · …` के रूप में दिखता है) से हटा सकता है — व्यवस्थापक द्वारा बनाए गए CLI टोकन भी — और यह 90 दिन बाद स्वतः समाप्त हो जाता है। एक सदस्य अधिकतम 5 रख सकता है; एक्सेस कुंजी से आए अतिथि टोकन नहीं बना सकते।

## 2. कनेक्ट करें

```bash
node cli/sharedesk.mjs login https://<आपका-डेस्क>
टोकन: (पेस्ट करें — स्क्रीन पर नहीं दिखेगा)
```

टोकन को **कमांड आर्ग्युमेंट के रूप में न दें**: यह शेल इतिहास और प्रोसेस सूची में रह जाता है। पूछे जाने पर पेस्ट करें, या पर्यावरण चर `SHAREDESK_TOKEN` में दें (`SHAREDESK_TOKEN` सेट हो तो `login` नहीं पूछता)। पता ध्यान से लिखें — टोकन उसी पते पर भेजा जाता है। सादा `http://` पता (localhost के अलावा) बिना एन्क्रिप्शन भेजता है और चेतावनी देता है।

पता और टोकन `~/.sharedesk/config.json` में सहेजे जाते हैं (जहाँ OS समर्थन करे, केवल आप पढ़ सकते हैं)। पर्यावरण चर `SHAREDESK_URL` और `SHAREDESK_TOKEN` फ़ाइल पर प्राथमिकता पाते हैं — CI या एजेंट सैंडबॉक्स में बिना फ़ाइल के काम आता है।

`npm run desk -- <कमांड>` से भी, और `npm install` के बाद `npx sharedesk <कमांड>` से भी वही CLI चलता है।

## 3. कमांड

| कमांड | काम |
| --- | --- |
| `status` | जाँचें कि कनेक्शन और टोकन चालू हैं |
| `ls [फ़ोल्डर पथ] [--json]` | फ़ोल्डर की वस्तुएँ (डिफ़ॉल्ट: डेस्कटॉप) |
| `get <फ़ाइल पथ> [गंतव्य]` | फ़ाइल डाउनलोड करें। गंतव्य फ़ोल्डर हो तो मूल नाम रहता है। मौजूदा फ़ाइल अधिलेखित होती है |
| `put <स्थानीय फ़ाइल> [फ़ोल्डर पथ] [--name नाम]` | फ़ाइल अपलोड करें (फ़ोल्डर पथ न दें तो डेस्कटॉप) |
| `mkdir <फ़ोल्डर पथ>` | फ़ोल्डर बनाएँ |

पथ डेस्कटॉप के सापेक्ष हैं और `/` से अलग होते हैं, जैसे `reports/2026/summary.pdf`। एक ही नाम की कई वस्तुएँ हों तो CLI अनुमान लगाने के बजाय रुक जाता है।

```bash
node cli/sharedesk.mjs ls
node cli/sharedesk.mjs ls "reports/2026" --json
node cli/sharedesk.mjs get "reports/2026/summary.pdf" ./downloads/
node cli/sharedesk.mjs put ./results.csv "reports/2026"
node cli/sharedesk.mjs mkdir "reports/2027"
```

`--json` के साथ परिणाम एक पंक्ति का JSON होता है जिसे एजेंट आसानी से पढ़ सकते हैं; त्रुटियाँ भी `{"ok":false,"error":...}` के रूप में आती हैं। निकास कोड: 0 सफल, 1 सामान्य त्रुटि, 2 उपयोग या सेटिंग अनुपस्थित, 3 टोकन समाप्त या हटाया गया।

## 4. यह कैसे काम करता है

- प्रमाणीकरण ब्राउज़र जैसा ही है: टोकन सत्र कुकी के रूप में भेजा जाता है, इसलिए सर्वर पर CLI के लिए कोई अलग दरवाज़ा नहीं है।
- डेस्क Google Drive मोड में हो तो अपलोड ब्राउज़र की तरह **सीधे Drive पर** जाते हैं (8 MiB के टुकड़े, टूटने पर फिर से जारी)। फ़ाइल सामग्री कभी ShareDesk सर्वर (Vercel) से नहीं गुज़रती, इसलिए आकार सीमाएँ ब्राउज़र जैसी हैं। स्थानीय मोड के डेस्क पर सर्वर अपलोड लेता है।
- अनुमतियाँ आपकी भूमिका के अनुसार हैं। केवल-देखने वाले सदस्यों के `put` और `mkdir` अस्वीकार होते हैं।
- केवल डिफ़ॉल्ट डेस्क शामिल है। स्पेस (`/<slug>/files`) अभी समर्थित नहीं हैं।

## 5. AI एजेंट के लिए उदाहरण प्रॉम्प्ट

```text
इस रिपॉज़िटरी का docs/CLI.hi.md पढ़ो और ShareDesk से कनेक्ट करो। टोकन पर्यावरण चर SHAREDESK_TOKEN में है।
डेस्कटॉप के "meeting-notes" फ़ोल्डर से इस सप्ताह की फ़ाइलें डाउनलोड करो, उनका सारांश बनाओ, और सारांश को summary.md नाम से उसी फ़ोल्डर में अपलोड करो।
टोकन कभी प्रिंट या कमिट मत करो।
```
