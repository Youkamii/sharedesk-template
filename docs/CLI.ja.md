# CLI でデスクを使う — ターミナルと AI エージェント

ShareDesk リポジトリに入っている `cli/sharedesk.mjs` 1 ファイルで、デスクのファイルを一覧・ダウンロード・アップロードできます。外部パッケージは不要で、Node 20 以上があれば動きます。コーディング AI（Claude Code、Codex など）にこの文書を読ませれば、AI がデスクを直接扱えます。

## 1. トークンを受け取る

1. デスクにサインインし、右のサイドバー（`»`）を開いて **CLI 接続** を押します。
2. どこで使うかを書き（任意）、**トークンを作成** を押します。
3. トークンは **そのとき一度だけ** 表示されます。**トークンをコピー** で控えてください。

トークンはあなたの名前で動作する端末セッションです。管理者はユーザー管理の端末セッション一覧（`CLI · …` と表示）から切断でき — 管理者自身が作った CLI トークンも切断できます — 90 日で自動的に失効します。1 人あたり 5 個まで持て、アクセスキーで入ったゲストは作成できません。

## 2. 接続する

```bash
node cli/sharedesk.mjs login https://<デスクのアドレス>
トークン: (貼り付け — 画面には表示されません)
```

トークンを **コマンド引数で渡さないでください。** シェルの履歴やプロセス一覧に残ります。求められたときに貼り付けるか、環境変数 `SHAREDESK_TOKEN` で渡します（`login` は環境変数があれば尋ねません）。アドレスは正確に — 入力したアドレスへトークンが送られます。`http://` のアドレス（ローカル以外）は暗号化なしで送るため警告が出ます。

アドレスとトークンは `~/.sharedesk/config.json` に保存されます（対応 OS では本人だけが読めます）。環境変数 `SHAREDESK_URL`・`SHAREDESK_TOKEN` は設定ファイルより優先されます — CI やエージェントのサンドボックスでファイルなしに使うときに便利です。

`npm run desk -- <コマンド>` でも、`npm install` 後は `npx sharedesk <コマンド>` でも同じ CLI を呼べます。

## 3. コマンド

| コマンド | 内容 |
| --- | --- |
| `status` | 接続とトークンが有効か確認 |
| `ls [フォルダパス] [--json]` | フォルダ内の項目（既定: デスクトップ） |
| `get <ファイルパス> [保存先]` | ファイルをダウンロード。保存先がフォルダなら元の名前で保存。同名ファイルは上書き |
| `put <ローカルファイル> [フォルダパス] [--name 名前]` | ファイルをアップロード（フォルダパス省略時はデスクトップ） |
| `mkdir <フォルダパス>` | フォルダを作成 |

パスはデスクトップ基準で `/` 区切りです。例: `reports/2026/summary.pdf`。同じ名前が複数あると CLI は選ばずに止まります。

```bash
node cli/sharedesk.mjs ls
node cli/sharedesk.mjs ls "reports/2026" --json
node cli/sharedesk.mjs get "reports/2026/summary.pdf" ./downloads/
node cli/sharedesk.mjs put ./results.csv "reports/2026"
node cli/sharedesk.mjs mkdir "reports/2027"
```

`--json` を付けると結果が 1 行の JSON になり、エージェントが解析しやすくなります。エラーも `{"ok":false,"error":...}` で返ります。終了コード: 0 成功、1 一般エラー、2 使い方・設定なし、3 トークン失効・切断。

## 4. 仕組み

- 認証はブラウザと同じです。トークンをセッション Cookie として送るので、サーバーに CLI 専用の入口はありません。
- デスクが Google Drive モードなら、アップロードはブラウザと同じく **Drive へ直接** 送られます（8 MiB のチャンク、切れても再開）。ファイル本体は ShareDesk サーバー（Vercel）を通らないため、サイズ制限はブラウザと同じです。ローカルモードのデスクはサーバーが受け取ります。
- 権限はあなたの役割に従います。閲覧専用メンバーは `put`・`mkdir` が拒否されます。
- 既定のデスクのみ対象です。スペース（`/<slug>/files`）はまだ未対応です。

## 5. AI エージェントへの依頼文の例

```text
このリポジトリの docs/CLI.ja.md を読み、ShareDesk に接続せよ。トークンは環境変数 SHAREDESK_TOKEN にある。
デスクトップの「議事録」フォルダから今週のファイルを取得して要約し、要約を summary.md として同じフォルダにアップロードせよ。
トークンを出力したりコミットしたりしないこと。
```
