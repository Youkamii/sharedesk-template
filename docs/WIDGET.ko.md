# ShareDesk 데스크톱 위젯

ShareDesk 위젯은 데스크를 바탕화면 구석에 작은 창으로 띄워 두는 선택 사항입니다. 설치하지 않아도 ShareDesk의 모든 기능은 브라우저에서 그대로 됩니다. 위젯은 새 앱이 아니라 **같은 데스크 주소를 여는 전용 창**이며, 화면은 데스크 서버가 그립니다. 그래서 호스트가 ShareDesk를 업데이트하면 위젯 화면도 바로 바뀝니다.

위젯이 브라우저와 다른 점은 넷입니다.

- 항상 화면에 있습니다. 탐색기에서 파일을 끌어다 놓으면 데스크에 올라갑니다.
- 다른 창 위에 떠 있거나(기본) 트레이에 숨겨 둘 수 있습니다.
- 접속 중인 사람과 최근 올라온 파일이 한눈에 보이는 **창가** 모드가 있습니다.
- 여러 개를 띄워 데스크마다 다른 계정으로 로그인해 둘 수 있습니다.

채팅은 위젯에 없습니다. 미리보기·이름 바꾸기·휴지통 같은 큰 작업은 위젯의 `↗` 버튼으로 브라우저를 열어 합니다.

## 설치

1. [위젯 내려받기](https://github.com/Youkamii/sharedesk-template/releases/tag/widget)에서 내 운영체제의 설치 파일을 받습니다. Windows는 [`sharedesk-widget-windows-x64-setup.exe`](https://github.com/Youkamii/sharedesk-template/releases/download/widget/sharedesk-widget-windows-x64-setup.exe)입니다(항상 최신 버전을 가리키는 고정 주소). macOS 파일은 맥에서 빌드해 올린 뒤에 나타납니다.
2. 설치 파일을 실행합니다. 관리자 권한은 필요 없습니다.
3. 처음 실행하면 **데스크 주소**를 묻습니다. 호스트가 준 ShareDesk 주소(예: `https://desk.example.com`)를 붙여 넣고 `데스크 열기`를 누릅니다.
4. 브라우저에서와 똑같이 로그인합니다. Google 로그인과 초대 코드 입력이 위젯 창 안에서 그대로 진행됩니다.

Windows에서 "알 수 없는 게시자" 경고가 나오면 `추가 정보 → 실행`으로 진행합니다. 설치 파일은 코드 서명이 없지만, 위젯의 자동 업데이트는 별도 서명키로 검증됩니다.

## 사용

- 위쪽 머리띠를 끌어 창을 옮기고, 창 가장자리를 끌어 크기를 바꿉니다.
- **서랍**: 데스크의 파일과 폴더가 격자로 보입니다. 파일을 떨어뜨리면 지금 보는 폴더에 올라갑니다. 폴더는 더블클릭으로 들어가고 `← 뒤로`로 나옵니다. 파일 더블클릭은 내려받기입니다. 우클릭 메뉴에서 내려받기·1시간 링크 복사·파일 올리기를 고를 수 있습니다.
- **창가**: 현재 접속 인원, 최근 올라온 파일 5개, 관리자에게는 데스크 용량이 보입니다. 파일을 누르면 내려받습니다.
- `↗`는 기본 브라우저에서 데스크를 엽니다. `–`는 위젯을 트레이로 숨깁니다. 트레이 아이콘을 누르면 다시 나옵니다.
- 트레이 아이콘 우클릭 메뉴: 위젯 보이기/숨기기, 항상 위, 부팅 시 실행, 데스크 주소 바꾸기, 브라우저에서 데스크 열기, 업데이트 확인, 종료.

위젯은 브라우저 탭과 같은 간격으로 데스크를 확인합니다. 트레이에 숨어 있는 동안은 훨씬 느리게 확인해 호스트의 서버를 아낍니다.

## 여러 데스크, 여러 계정

위젯 하나는 데스크 주소 하나를 가집니다. 다른 데스크를 함께 두려면 **프로필**을 나눠 하나 더 실행합니다. 프로필마다 로그인과 데스크 주소가 따로 저장되므로 같은 Google 계정으로 데스크 A와 B에 각각 로그인해 둘 수 있습니다.

바로 가기의 대상 끝에 프로필 이름을 붙입니다.

```text
"C:\Users\내이름\AppData\Local\ShareDesk Widget\sharedesk-widget.exe" --profile work
```

프로필 이름은 영문·숫자·`-`·`_`만 쓸 수 있습니다. 지정하지 않으면 `default`입니다. `--desk https://desk.example.com`을 함께 주면 첫 실행 화면 없이 그 주소로 바로 엽니다.

## 자동 업데이트

위젯은 실행 후 잠시 뒤와 트레이 메뉴의 `업데이트 확인`에서 새 껍데기 버전을 확인합니다. 새 버전이 있으면 트레이 메뉴에 `업데이트 설치`가 나타나고, 누르면 받아서 설치한 뒤 다시 켜집니다. 사용자가 누르기 전에는 스스로 재시작하지 않습니다.

데스크 화면 자체는 서버에서 오므로 껍데기 업데이트와 무관하게 항상 최신입니다.

## 데이터 위치와 삭제

프로필(쿠키·데스크 주소·창 위치)은 사용자 폴더 아래에 있습니다.

- Windows: `%APPDATA%\com.youkamii.sharedesk-widget\profiles\<프로필>`
- macOS: `~/Library/Application Support/com.youkamii.sharedesk-widget/profiles/<프로필>`

위젯을 지워도 이 폴더는 남으므로 완전히 지우려면 함께 삭제합니다. 위젯이 이야기하는 상대는 데스크 서버, 로그인 때의 Google, 그리고 업데이트 확인·내려받기 때의 GitHub 공개 릴리스뿐입니다. 데스크 화면이 브라우저에서 하는 통신과 같습니다.

## 호스트를 위한 발행 방법

위젯 껍데기는 이 저장소의 `widget/` 폴더에 있고, 공개 템플릿 저장소의 고정 릴리스 `widget`(prerelease)에 발행합니다. 발행하는 컴퓨터에 Rust·Node·`gh` 로그인과 서명 비밀키(`~/.tauri/sharedesk-widget.key`)가 있어야 합니다.

```powershell
node scripts/widget-release.mjs --dry-run   # 빌드·서명·latest.json 확인
node scripts/widget-release.mjs             # 릴리스에 업로드
```

버전을 올릴 때는 `widget/src-tauri/tauri.conf.json`, `widget/src-tauri/Cargo.toml`, `widget/package.json`의 버전을 함께 바꿉니다. macOS 파일은 맥에서 같은 명령을 실행하면 같은 릴리스에 더해집니다.
