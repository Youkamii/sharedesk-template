# ShareDesk デスクトップウィジェット

ShareDesk ウィジェットは、デスクをデスクトップの隅に小さな窓として置いておく任意の機能です。入れなくても ShareDesk の機能はすべてブラウザでそのまま使えます。ウィジェットは別のアプリではなく **同じデスクのアドレスを開く専用の窓** で、画面はデスクのサーバーが描きます。ホストが ShareDesk を更新すると、ウィジェットの画面もすぐに変わります。

ブラウザのタブと違う点は四つです。

- いつも画面にあります。エクスプローラーや Finder からファイルをドロップすると、デスクにアップロードされます。
- ほかの窓の上に浮かせる（既定）か、トレイに隠しておけます。
- 接続中の人と最近アップロードされたファイルがひと目で分かる **窓辺** モードがあります。
- 複数起動して、デスクごとに別のアカウントでログインしておけます。

チャットはウィジェットにはありません。プレビュー・名前の変更・ゴミ箱のような大きな操作は、ウィジェットの `↗` ボタンでブラウザを開いて行います。

## インストール

1. [ウィジェットのダウンロード](https://github.com/Youkamii/sharedesk-template/releases/tag/widget) から自分の OS のインストーラーを取得します。Windows は [`sharedesk-widget-windows-x64-setup.exe`](https://github.com/Youkamii/sharedesk-template/releases/download/widget/sharedesk-widget-windows-x64-setup.exe) です（常に最新版を指す固定アドレス）。macOS のファイルは Mac でビルドしてアップロードされた後に現れます。
2. インストーラーを実行します。管理者権限は不要です。
3. 初回起動時に **デスクのアドレス** を尋ねられます。ホストから受け取った ShareDesk のアドレス（例: `https://desk.example.com`）を貼り付けて `デスクを開く` を押します。
4. ブラウザと同じようにログインします。Google ログインと招待コードの入力はウィジェットの窓の中で進みます。

Windows で「発行元不明」の警告が出たら `詳細情報 → 実行` で進みます。インストーラーにコード署名はありませんが、ウィジェットの自動更新は別の署名鍵で検証されます。

## 使い方

- 上のバンドをドラッグして窓を動かし、窓の端をドラッグして大きさを変えます。
- **引き出し**: デスクのファイルとフォルダが格子で並びます。ファイルをドロップすると、いま見ているフォルダにアップロードされます。フォルダはダブルクリックで入り、`← 戻る` で出ます。ファイルのダブルクリックはダウンロードです。右クリックメニューからダウンロード・1時間リンクのコピー・ファイルのアップロードを選べます。
- **窓辺**: 現在の接続人数、最近アップロードされたファイル 5 件、管理者にはデスクの容量が見えます。ファイルを押すとダウンロードします。
- `↗` は既定のブラウザでデスクを開きます。`–` はウィジェットをトレイに隠します。トレイアイコンを押すと戻ります。
- トレイアイコンの右クリックメニュー: ウィジェットの表示/非表示、常に手前に表示、ログイン時に起動、デスクのアドレスを変更、ブラウザでデスクを開く、アップデートを確認、終了。

ウィジェットはブラウザのタブと同じ間隔でデスクを確認します。トレイに隠れている間はずっと間隔を空けて、ホストのサーバーを節約します。

## 複数のデスク、複数のアカウント

ウィジェット一つはデスクのアドレス一つを持ちます。別のデスクを並べるには、**プロファイル** を分けてもう一つ起動します。プロファイルごとにログインとデスクのアドレスが別々に保存されるので、同じ Google アカウントでデスク A と B に同時にログインしておけます。

ショートカットのリンク先の末尾にプロファイル名を付けます。

```text
"C:\Users\自分\AppData\Local\ShareDesk Widget\sharedesk-widget.exe" --profile work
```

プロファイル名に使えるのは英数字・`-`・`_` だけです。指定しなければ `default` です。`--desk https://desk.example.com` を添えると初回画面を飛ばしてそのアドレスを直接開きます。

## 自動更新

ウィジェットは起動後しばらくしてから、またトレイメニューの `アップデートを確認` で、新しいシェルのバージョンを確認します。新しいバージョンがあるとトレイメニューに `アップデートをインストール` が現れ、押すとダウンロードしてインストールし、再起動します。ユーザーが押すまで勝手に再起動しません。

デスクの画面そのものはサーバーから来るので、シェルの更新とは関係なく常に最新です。

## データの場所と削除

プロファイル（Cookie・デスクのアドレス・窓の位置）はユーザーフォルダの下にあります。

- Windows: `%APPDATA%\com.youkamii.sharedesk-widget\profiles\<プロファイル>`
- macOS: `~/Library/Application Support/com.youkamii.sharedesk-widget/profiles/<プロファイル>`

ウィジェットをアンインストールしてもこのフォルダは残るので、完全に消すには一緒に削除します。ウィジェットが通信するのは、デスクのサーバー、ログイン時の Google、そして更新の確認・ダウンロード時の GitHub 公開リリースだけです。ブラウザでデスク画面が行う通信と同じです。

## ホスト向け: 公開方法

ウィジェットのシェルはこのリポジトリの `widget/` フォルダにあり、公開テンプレートリポジトリの固定リリース `widget`（prerelease）に公開します。公開するマシンには Rust・Node・ログイン済みの `gh`・署名鍵（`~/.tauri/sharedesk-widget.key`）が必要です。

```powershell
node scripts/widget-release.mjs --dry-run   # ビルド・署名・latest.json の確認
node scripts/widget-release.mjs             # リリースへアップロード
```

バージョンを上げるときは `widget/src-tauri/tauri.conf.json`・`widget/src-tauri/Cargo.toml`・`widget/package.json` のバージョンを一緒に変えます。Mac で同じコマンドを実行すると macOS のファイルが同じリリースに追加されます。
