# CLI로 데스크 쓰기 — 터미널과 AI 에이전트

ShareDesk 저장소에 들어 있는 `cli/sharedesk.mjs` 한 파일로 데스크의 파일을 보고, 받고, 올릴 수 있습니다. 외부 패키지 없이 Node 20 이상이면 됩니다. 코딩 AI(Claude Code, Codex 등)에게 이 문서를 읽히면 AI가 데스크를 직접 드나듭니다.

## 1. 토큰 받기

1. 데스크에 로그인한 뒤 오른쪽 사이드바(`»`)를 열고 **CLI 연결**을 누릅니다.
2. 어디서 쓰는지 적고(선택) **토큰 만들기**를 누릅니다.
3. 토큰은 **그때 한 번만** 보입니다. **토큰 복사**로 복사해 두세요.

토큰은 내 이름으로 동작하는 기기 세션입니다. 관리자가 사용자 관리의 기기 세션 목록(`CLI · …`로 표시)에서 끊을 수 있고 — 관리자 본인이 만든 CLI 토큰도 끊을 수 있습니다 — 90일이 지나면 저절로 만료됩니다. 한 사람이 5개까지 가질 수 있고, 접속 키로 들어온 손님은 만들 수 없습니다.

## 2. 연결

```bash
node cli/sharedesk.mjs login https://<데스크 주소>
토큰: (붙여 넣기 — 화면에 보이지 않습니다)
```

토큰은 **명령 인자로 주지 마세요.** 셸 기록과 프로세스 목록에 남습니다. 물어볼 때 붙여 넣거나, 환경변수 `SHAREDESK_TOKEN`으로 줍니다(`login`은 환경변수가 있으면 묻지 않습니다). 주소는 정확히 — 입력한 주소로 토큰이 전송됩니다. `http://` 주소(로컬 제외)는 암호화 없이 보내므로 경고가 뜹니다.

`~/.sharedesk/config.json`에 주소와 토큰이 저장됩니다(가능한 OS에서는 본인만 읽을 수 있게). 환경변수 `SHAREDESK_URL`·`SHAREDESK_TOKEN`을 주면 설정 파일보다 우선합니다 — CI나 에이전트 샌드박스에서 파일 없이 쓸 때 편합니다.

`npm run desk -- <명령>`으로도, `npm install` 뒤에는 `npx sharedesk <명령>`으로도 같은 CLI를 부를 수 있습니다.

## 3. 명령

| 명령 | 하는 일 |
| --- | --- |
| `status` | 연결과 토큰이 살아 있는지 확인 |
| `ls [폴더 경로] [--json]` | 폴더 안 항목 (기본: 바탕화면) |
| `get <파일 경로> [저장 위치]` | 파일 받기. 저장 위치가 폴더면 그 안에 원래 이름으로. 같은 이름 파일은 덮어씁니다 |
| `put <로컬 파일> [폴더 경로] [--name 이름]` | 파일 올리기 (폴더 경로 생략 시 바탕화면) |
| `mkdir <폴더 경로>` | 폴더 만들기 |

경로는 바탕화면 기준이고 `/`로 나눕니다. 예: `보고서/2026/요약.pdf`. 같은 이름이 여러 개면 CLI가 고르지 않고 멈춥니다.

```bash
node cli/sharedesk.mjs ls
node cli/sharedesk.mjs ls "보고서/2026" --json
node cli/sharedesk.mjs get "보고서/2026/요약.pdf" ./다운로드/
node cli/sharedesk.mjs put ./결과.csv "보고서/2026"
node cli/sharedesk.mjs mkdir "보고서/2027"
```

`--json`을 붙이면 결과가 한 줄 JSON으로 나와 에이전트가 파싱하기 쉽습니다. 오류도 `{"ok":false,"error":...}`로 나옵니다. 종료 코드: 0 성공, 1 일반 오류, 2 사용법·설정 없음, 3 토큰 만료·끊김.

## 4. 어떻게 동작하나

- 인증은 브라우저와 같습니다. 토큰을 세션 쿠키로 보내므로 서버에 CLI 전용 문이 없습니다.
- 업로드는 데스크가 Google Drive 모드면 브라우저와 똑같이 **Drive로 직행**합니다(8 MiB 조각, 끊기면 이어 올리기). 파일 본문이 ShareDesk 서버(Vercel)를 지나지 않아 용량 제한이 브라우저와 같습니다. 로컬 모드 데스크는 서버가 받습니다.
- 권한은 내 역할을 따릅니다. 보기 전용 멤버는 `put`·`mkdir`가 거부됩니다.
- 기본 데스크만 다룹니다. 스페이스(`/<slug>/files`)는 아직 지원하지 않습니다.

## 5. AI 에이전트에게 주는 요청문 예

```text
이 저장소의 docs/CLI.ko.md를 읽고 ShareDesk에 연결해라. 토큰은 환경변수 SHAREDESK_TOKEN에 있다.
바탕화면의 "회의록" 폴더에서 이번 주 파일을 받아 요약한 뒤, 요약을 summary.md로 같은 폴더에 올려라.
토큰은 출력하거나 커밋하지 마라.
```
