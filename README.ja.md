# ShareDesk

### 言語

[English](./README.md) · [한국어](./README.ko.md) · **日本語** · [हिन्दी](./README.hi.md) · [中文](./README.zh.md)

ShareDesk は **ひとりの Google Drive の保存容量を、複数の人がそれぞれの Google アカウントで一緒に使う共有ファイルスペース**です。インストールするのはホストが最初に一度だけ。参加者は同じアドレスでログインして招待コードを入力するだけで、同じファイルとフォルダを一緒に使えます。

## できること

### デスクトップとファイル

- ファイルやフォルダをデスクトップアイコンのように並べ、複数のフォルダをウィンドウとして開いてまとめて整理できます。
- 役割に応じて、ファイルのアップロード、ダウンロード、名前の変更、移動、削除、ごみ箱からの復元ができます。
- 写真、動画、音声、PDF、テキストをその場で表示でき、`.txt` ファイルはみんなで編集できます。
- フォルダごとに共有メモを残せます。
- フォルダ、検索、ごみ箱、プレビュー、フォルダメモ、クイックリンク、作成済みリンクの各ウィンドウは最小化・最大化できます。チャットはコンパクトなまま、最小化だけに対応しています。

### みんなで使う

- 招待コードで人を招き、現在オンラインのメンバーを確認できます。
- 右下の専用ボタンからチャットを開けます。チャットを最小化している間に新しいメッセージが届くと、ボタンがやさしく点滅し、未読件数が表示されます。
- `ADMIN_EMAILS` で管理者を指定し、管理画面では各参加者の権限を「編集可」「アップロード可」「閲覧のみ」の3種類から変更できます。

### 共有と転送

- 編集権限を持つ参加者と管理者は、ファイルやフォルダを右クリックするだけで、ログイン不要の1時間限定共有リンクをすぐに作成してコピーできます。
- **その他の機能**を開くと、クイックリンク、作成済みリンク、ダウンロード優先を選べます。チャットは独立したボタンのままです。
- **クイックリンク**では、ドロップしたファイルのアップロードが完了するたびに1時間限定リンクがすぐ発行されます。リンクは作成から1時間でアクセスできなくなり、チェックが付いたファイルはその時点で完全削除待ちとなって、その後のクリーンアップで削除されます。チェックを外すとデスクトップに残せます。
- **作成済みリンク**では、管理できる有効なリンクを一覧で確認し、アドレスのコピーや共有の停止をいつでも行えます。
- **ダウンロード優先**を有効にすると、プレビューとダウンロードの両方が可能なファイルを開いたとき、プレビューせずにダウンロードします。

### 容量とカスタマイズ

- 管理者は、アップロードするファイル1件あたりの最大容量と、現在のデスクが使える合計容量の両方を制限できます。
- レトロなディスク風のドーナツ表示で、デスクの使用量、アップロード中の容量、デスクの残り容量を確認できます。制限値の横には、ホストの Drive 全体の容量情報も表示されます。
- 画面の言語は英語、韓国語、日本語、ヒンディー語、中国語の5種類です。管理者がデスクの言語を決め、各メンバーが自分の言語を選べるようにすることもできます。
- 4つの壁紙から好きな雰囲気を選べます。選択は各自のブラウザに保存されます。

## どうやって共有するの？

```text
  ホストひとりの Google Drive
             ↕
    同じ ShareDesk アドレス
   ├─ ホストの Google アカウント
   ├─ 参加者 A の Google アカウント
   └─ 参加者 B の Google アカウント
```

Google Drive に接続するのはホストのアカウントだけです。参加者はそれぞれの Google アカウントでログインしますが、ShareDesk の中では、ホストが選んだひとつの Drive フォルダのファイルと容量をみんなで共有します。ShareDesk が参加者個人の Drive ファイルを読むことはありません。

ユーザー、招待、チャット、フォルダメモ、共有リンクの記録、設定、アイコン配置といった共有状態もホストの Drive に保存されます。別のデータベースは必要ありません。

ShareDesk はサーバーレス環境での運用を前提に設計されています。チャットは常時接続の WebSocket ではなく軽量なポーリングを使うため、常に動き続けるサーバーがなくても利用できます。

ひとつのインストールアドレスが、ひとつのデスクに対応します。ひとつのインストール内に複数のデスクが作られることはありません。同じ Google アカウントで別々の ShareDesk アドレスに複数参加できますが、メンバー、権限、容量制限、ファイル、チャットが混ざることはありません。
